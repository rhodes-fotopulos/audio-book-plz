### Issues Found (2)

**1. Dead flag: `--voice-threshold` on `assemble` command (POL-04)**
- `main.py` `assemble` command accepts `--voice-threshold` but never passes it to any function
- User sets threshold and nothing happens — no error, no voice check
- Works correctly via `convert` command
- Fix: wire `run_voice_check()` into `assemble` command body, or remove the flag

**2. Missing flag: `--libritts-audio` on `synthesize` command (TTS-04)**
- Standalone `synthesize` subcommand cannot pass LibriTTS-R audio directory
- Voice references prepared without transcripts/SNR scoring when using standalone synthesize
- Works correctly via `convert` command
- Fix: add `--libritts-audio` option to `synthesize` command

### Broken Flows (1)

**`python main.py assemble book/ --voice-threshold 0.80`**
- Flag parsed by Typer, value silently discarded
- No voice consistency check runs
- User has no indication the flag was ignored
