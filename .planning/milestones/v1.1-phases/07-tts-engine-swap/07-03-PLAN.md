  <action>
Update `src/synthesis/checkpoint.py`:

1. Modify `create_checkpoint()`:
   - Add parameters: `engine_name: str`, `engine_version: str`, `engine_library: str`.
   - Add `"engine"` dict to checkpoint with keys: `name`, `version`, `library`, `library_version`.
   - Keep existing `"config"` dict for backward compatibility, but replace hardcoded `"model": "chatterbox-500m"` with the engine name from parameters.
   - Example engine section:
     ```python
     "engine": {
         "name": engine_name,           # "qwen3-tts-1.7b" or "chatterbox-500m"
         "version": engine_version,     # mlx-audio version or chatterbox-tts version
         "library": engine_library,     # "mlx-audio" or "chatterbox-tts"
     }
     ```

2. Add `check_engine_compatibility(checkpoint: dict, engine_name: str) -> tuple[bool, str]`:
   - Compare checkpoint's `engine.name` with current `engine_name`.
   - If match: return `(True, "")`.
   - If mismatch: return `(False, f"Checkpoint uses {cp_engine}, current engine is {engine_name}")`.
   - If checkpoint has no `engine` key (legacy v1.0 checkpoint): return `(False, "Legacy v1.0 checkpoint (no engine metadata)")`.

3. Add `archive_checkpoint(book_dir: Path) -> Path | None`:
   - Per user decision: auto-archive old v1.0 checkpoints — move to backup folder automatically, then start fresh.
   - Creates `book_dir/checkpoint_archive/` directory.
   - Moves `checkpoint.json` to `checkpoint_archive/checkpoint_{timestamp}.json`.
   - Moves entire `wavs/` directory to `checkpoint_archive/wavs_{timestamp}/` (per user decision: full re-run only — don't mix engines).
   - Returns the archive directory path, or None if nothing to archive.
   - Log: "Archived old checkpoint and WAVs to {archive_path}".

4. Update `load_checkpoint()`:
   - After loading, add a convenience accessor: if loaded checkpoint lacks `"engine"` key, it's a v1.0 legacy checkpoint. Log a note about this.
  </action>

2. Rewrite `src/synthesis/synthesizer.py` — this is the core integration:
   - Remove old `_split_long_text()` function (moved to chunker.py in Plan 07-02).
   - Import from new modules:
     - `from src.synthesis.engine_factory import create_engine`
     - `from src.synthesis.engine_base import TTSEngineBase, AudioResult`
     - `from src.synthesis.chunker import chunk_text_qwen, chunk_text_chatterbox`
     - `from src.synthesis.voice_prep import prepare_all_voice_references, VoiceReference`
     - `from src.synthesis.checkpoint import check_engine_compatibility, archive_checkpoint`
   - Update `run_synthesis()`:
     a. **Engine creation:** Replace `engine = TTSEngine(config)` with `engine = create_engine(config)`.
     b. **Checkpoint engine check:** After `load_checkpoint()`, call `check_engine_compatibility(cp, engine.engine_name)`. If incompatible, call `archive_checkpoint(book_dir)` and create fresh checkpoint using updated `create_checkpoint()` with engine metadata.
     c. **Voice prep:** Before synthesis loop, call `prepare_all_voice_references(voice_map, libritts_root)` to get `VoiceReference` objects with transcripts. Build voice_lookup to include transcript: `voice_lookup[name] = {"clip_path": ..., "speaker_id": ..., "transcript": ref.transcript}`.
     d. **Chunking:** Replace `_split_long_text(text)` calls with `chunk_text_qwen(text)` when engine is Qwen3, or `chunk_text_chatterbox(text)` for Chatterbox. Select based on `config.engine_type`.
     e. **Generation with transcript:** Pass `ref_transcript=voice["transcript"]` to `engine.generate()`.
     f. **Auto-fallback:** Wrap engine.generate() in try/except. On failure:
        - If config.engine_type is "qwen3", create a Chatterbox fallback engine (lazy — only instantiate on first failure, store as `fallback_engine`). Load it, then retry with Chatterbox chunking.
        - Track fallback events: append `{"segment_id": seg_id, "error": str(exc), "timestamp": ...}` to a `fallback_events` list.
        - Log each fallback: `"Qwen3 failed seg_{id}, falling back to Chatterbox: {error}"`.
        - Per user decision: warn if fallback rate exceeds threshold but continue (don't abort).
     g. **Memory cleanup:** Use `engine.cleanup_memory()` which dispatches to the correct backend (MLX or MPS). For Qwen3, use `config.mlx_cleanup_interval` (default 50). For Chatterbox, use existing `config.cleanup_interval` (default 15).
     h. **Fallback summary at end:** After synthesis loop, if any fallback events occurred:
        - Log: `"Fallback summary: {N} segments fell back to Chatterbox out of {total}"`.
        - If fallback rate > 0.1 (10%), log warning: `"High fallback rate ({pct}%) — consider investigating Qwen3-TTS issues"`.
     i. **Updated checkpoint saving:** Pass engine.engine_name, engine.engine_version to create_checkpoint.
   - Add `libritts_root: Path` parameter to `run_synthesis()` signature (needed for voice prep). If None, skip voice prep and use raw clip paths (backward compatible).
   - Update `create_checkpoint()` calls to pass engine metadata.
