  <name>Task 1: Implement model selection and lifecycle in llm_client.py</name>
  <files>src/attribution/llm_client.py, pyproject.toml</files>
  <action>
  Add `psutil>=5.9` to pyproject.toml dependencies.

  Refactor `src/attribution/llm_client.py`:

  1. Replace the hardcoded `MODEL = "qwen3:8b"` with model selection:
     - Add constants: `MODEL_14B = "qwen3:14b"`, `MODEL_8B = "qwen3:8b"`, `DEFAULT_MODEL = MODEL_14B`
     - Add `RAM_THRESHOLD_GB = 12.0` (14B Q4_K_M ~10GB weights + ~2GB KV cache q8_0; 12GB leaves headroom)
     - Add module-level `_active_model: str | None = None` to track current model

  2. Add `select_model(override: str | None = None) -> str`:
     - If `override` is not None: return override directly (user forced a model)
     - Use `psutil.virtual_memory().available` to get available RAM in GB
     - If available >= RAM_THRESHOLD_GB: return MODEL_14B
     - Otherwise: log WARNING with clear message "Available RAM {X}GB below {threshold}GB threshold -- falling back to {MODEL_8B} (attribution quality may be reduced)" and return MODEL_8B
     - Set `_active_model` to selected model

  3. Add `preload_model(model: str | None = None) -> str`:
     - If model is None, call `select_model()` to auto-select
     - Call `ollama_chat(model=model, messages=[], keep_alive=-1)` to preload and pin in memory
     - Set `_active_model = model`
     - Log INFO "Model {model} preloaded with keep_alive=-1 (resident until explicit unload)"
     - Return the model name

  4. Add `get_active_model() -> str`:
     - If `_active_model` is not None, return it
     - Otherwise call `select_model()` and return result

  5. Modify `call_llm_structured()`:
     - Change `model=MODEL` to `model=get_active_model()`
     - Add `keep_alive=-1` to the ollama_chat() options to ensure model stays loaded
     - Keep all existing retry logic, /no_think, temperature=0

  6. Modify existing `unload_model()`:
     - Change signature to `unload_model(model: str | None = None) -> None`
     - If model is None, use `_active_model` or `DEFAULT_MODEL`
     - Reset `_active_model = None` after unload
     - Keep existing keep_alive=0 and error handling

  7. Add KV cache quantization guidance in module docstring:
     - Note: "For 14B on 16GB machines, set OLLAMA_KV_CACHE_TYPE=q8_0 environment variable to halve KV cache memory"
  </action>

  Verify psutil is in pyproject.toml: `grep psutil pyproject.toml`
  </verify>

  </done>
