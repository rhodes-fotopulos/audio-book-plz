     - Return list of SceneMood objects

     - High threshold: only flag lines with EXTREME contrast (per user decision):
       - Joy/laughter in a sadness/anger scene

       - Anger/shouting in a neutral/tenderness scene
     - Build LLM prompt with scene mood + segment text, asking: "Which lines (if any) have emotion SHARPLY different from the scene mood? Most lines should follow scene mood. Only flag extreme contrasts."
     - Use `call_llm_structured()` with LineOverrideResult schema
     - One LLM call per chapter (all scenes bundled)
     - If LLM returns no overrides, that's correct — most chapters have few or no overrides
     - Return list of LineOverride objects

  <files>src/synthesis/post_processor.py, src/synthesis/synthesizer.py, src/synthesis/__init__.py</files>
  <action>
  1. Create `src/synthesis/post_processor.py`:

     **Speech-act parameter mapping** (per user decisions):
     ```python
     SPEECH_ACT_PARAMS = {
         "spoken":    {"volume_db": 0.0,  "speed_factor": 1.0},
         "whispered": {"volume_db": -4.5, "speed_factor": 1.0},   # Midpoint of -3 to -6 dB
         "shouted":   {"volume_db": +4.5, "speed_factor": 1.08},  # Midpoint of +3 to +6, slight speed
         "thought":   {"volume_db": -3.0, "speed_factor": 0.93},  # Quieter + slower
     }
     ```
     Note: Adjustments are ABSOLUTE per speech-act type, NOT cumulative with scene mood (per user decision).

     **`apply_speech_act_adjustments(audio: np.ndarray, sample_rate: int, speech_act: str) -> tuple[np.ndarray, int]`**:
     - Look up params from SPEECH_ACT_PARAMS (default to "spoken" for unknown)
     - Volume adjustment: multiply audio by `10 ** (volume_db / 20.0)`, then `np.clip(audio, -1.0, 1.0)` to prevent clipping
     - Speed adjustment: if speed_factor != 1.0, use numpy interpolation:
       `new_length = int(len(audio) / speed_factor)`
       `audio = np.interp(np.linspace(0, len(audio)-1, new_length), np.arange(len(audio)), audio)`
     - Return (adjusted_audio, sample_rate)
     - If speech_act is "spoken", return audio unchanged (no-op fast path)

     **`get_adjustment_params(speech_act: str) -> dict`**: Returns the parameter dict for a speech-act (for logging/debugging).

  2. Update `src/synthesis/synthesizer.py`:
     - Import `apply_speech_act_adjustments` from `src.synthesis.post_processor`
     - In the segment synthesis loop (after `_generate_segment_audio()` succeeds and before `save_wav_atomic()`):
       a) Get speech_act from segment dict: `speech_act = seg.get("speech_act", "spoken")`
       b) If speech_act != "spoken":
          - Call `apply_speech_act_adjustments(audio_result.audio, audio_result.sample_rate, speech_act)`
          - Create new AudioResult with adjusted audio
          - Log at debug level: "Applied {speech_act} adjustments to seg_{seg_id}"
       c) Proceed with save_wav_atomic as before
     - Apply SAME post-processing in the fallback engine path (Chatterbox fallback) and the end-of-run retry path

  3. Update `src/synthesis/__init__.py`:
     - Add `apply_speech_act_adjustments` to exports
