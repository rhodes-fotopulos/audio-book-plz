  <action>
    Create `src/synthesis/` package.

    **src/synthesis/models.py** — Define data models:

    - `SynthesisConfig` (dataclass): Holds all tuning parameters.
      - `narration_exaggeration: float = 0.25` — Low for calm narration delivery
      - `dialogue_exaggeration: float = 0.45` — Higher for expressive character voices
      - `cfg_weight: float = 0.3` — Low for natural pacing (user decision: lean natural)
      - `max_retries: int = 3` — Per-segment retry count
      - `failure_threshold: float = 0.15` — Stop run if >15% segments fail (configurable per user decision)
      - `cleanup_interval: int = 15` — gc.collect() + cache clear every N segments (mitigates memory leak)
      - `min_wav_duration_s: float = 0.1` — Below this, WAV considered corrupted
      - `device: str = "auto"` — "auto" detects MPS/CPU; also accepts "mps", "cpu"

    - `SegmentResult` (dataclass): Per-segment synthesis outcome.
      - `segment_id: int`
      - `wav_path: str`
      - `duration_s: float`
      - `generation_time_s: float`
      - `character_name: str`
      - `success: bool`
      - `error: str | None = None`
      - `attempts: int = 1`

    - `SynthesisStats` (dataclass): Run-level statistics for the completion summary.
      - `total_segments: int`
      - `completed: int`
      - `failed: int`
      - `skipped_cached: int`
      - `total_audio_duration_s: float`
      - `total_wall_time_s: float`
      - `chapters_completed: int`
      - `total_chapters: int`

    **src/synthesis/tts_engine.py** — TTSEngine class:

    - `__init__(self, config: SynthesisConfig)` — Store config, model=None, device=None.

    - `ensure_ollama_unloaded(self)` — Import and call `unload_model()` from `src.attribution.llm_client`. Additionally, try `ollama.list()` to check for any loaded models. If models are loaded with non-zero size, call `unload_model()` for each. Log what was unloaded. Silently handle connection errors (Ollama might not be running). This fulfills SYNTH-03.

    - `load_model(self)` — Set `os.environ["PYTORCH_ENABLE_MPS_FALLBACK"] = "1"` BEFORE any torch import. Then:
      1. Call `self.ensure_ollama_unloaded()` first
      2. Import `ChatterboxTTS` from `chatterbox.tts` (import inside method to avoid loading torch at module level)
      3. Load model to CPU: `model = ChatterboxTTS.from_pretrained("cpu")`
      4. Detect device: if config.device == "auto", check `torch.backends.mps.is_available()` -> "mps", else "cpu". If config.device is explicit, use that.
      5. If device == "mps": migrate components individually — iterate `("t3", "s3gen", "ve")`, move each to device if attribute exists. Set `model.device = device`.
      6. Store `self.model` and `self.device`. Log device and model info.

    - `generate(self, text: str, ref_clip_path: str, segment_type: str = "narration", exaggeration: float | None = None, cfg_weight: float | None = None) -> torch.Tensor` —
      1. If exaggeration is None: use config narration_exaggeration or dialogue_exaggeration based on segment_type.
      2. If cfg_weight is None: use config cfg_weight.
      3. Call `self.model.generate(text, audio_prompt_path=ref_clip_path, exaggeration=exaggeration, cfg_weight=cfg_weight)`.
      4. Return the wav tensor.

    - `save_wav_atomic(self, wav_tensor: torch.Tensor, output_path: str) -> bool` —
      1. Calculate duration: `wav_tensor.shape[-1] / self.model.sr`.
      2. If duration < config.min_wav_duration_s: log warning, return False.
      3. Create parent directory if needed: `os.makedirs(os.path.dirname(output_path), exist_ok=True)`.
      4. Save to tmp: `torchaudio.save(output_path + ".tmp", wav_tensor, self.model.sr)`.
      5. Atomic rename: `os.rename(output_path + ".tmp", output_path)`.
      6. Return True.

    - `cleanup_memory(self)` —
      Call `gc.collect()`. If device == "mps": `torch.mps.empty_cache()`. If device == "cuda": `torch.cuda.empty_cache()`.

    - `sample_rate` property — Return `self.model.sr`.

    - `unload(self)` — Set `self.model = None`, call `cleanup_memory()`, call `gc.collect()`.

    **src/synthesis/__init__.py** — Export TTSEngine, SynthesisConfig, SegmentResult, SynthesisStats, and checkpoint functions (added in Task 2).

    CRITICAL: Do NOT import from `chatterbox` at module level. The import happens inside `load_model()` to avoid loading torch/torchaudio when the synthesis package is merely imported (e.g., during CLI help).

    **src/synthesis/checkpoint.py** — Checkpoint management:

    - `CHECKPOINT_FILENAME = "checkpoint.json"` — Stored alongside WAVs in the book output dir.

    - `create_checkpoint(book_slug: str, total_segments: int, config: SynthesisConfig) -> dict` —
      Return a new checkpoint dict:
      ```python
      {
          "book_slug": book_slug,
          "started_at": datetime.utcnow().isoformat() + "Z",
          "updated_at": datetime.utcnow().isoformat() + "Z",
          "total_segments": total_segments,
          "completed": {},    # segment_id (str) -> {"wav": path, "duration_s": float, "took_s": float}
          "failed": {},       # segment_id (str) -> {"error": str, "attempts": int}
          "config": {
              "narration_exaggeration": config.narration_exaggeration,
              "dialogue_exaggeration": config.dialogue_exaggeration,
              "cfg_weight": config.cfg_weight,
              "device": config.device,
              "model": "chatterbox-500m",
          }
      }
      ```

    - `save_checkpoint(checkpoint: dict, checkpoint_dir: Path) -> None` —
      Write checkpoint to `checkpoint_dir / CHECKPOINT_FILENAME` with json.dump, indent=2.
      Use atomic write pattern: write to `.tmp` then rename.

    - `load_checkpoint(checkpoint_dir: Path) -> dict | None` —
      If checkpoint file exists, load and return. Otherwise return None.

    - `validate_checkpoint(checkpoint: dict, wavs_dir: Path, min_duration_s: float = 0.1) -> tuple[dict, list[str]]` —
      Validate that all "completed" WAVs actually exist on disk and meet minimum file size (proxy for duration).
      1. For each segment_id in checkpoint["completed"]:
         - Check if wav_path exists
         - Check file size > 0 (at minimum)
         - If file missing or empty: remove from completed, add segment_id to re_queue list
      2. Return (cleaned_checkpoint, re_queue_ids).
      This implements the user decision: "Re-synthesis: delete the WAV file and re-run — checkpoint detects missing file and regenerates."

    - `mark_completed(checkpoint: dict, segment_id: int, wav_path: str, duration_s: float, took_s: float) -> None` —
      Add to checkpoint["completed"], remove from checkpoint["failed"] if present, update "updated_at".

    - `mark_failed(checkpoint: dict, segment_id: int, error: str, attempts: int) -> None` —
      Add/update checkpoint["failed"], update "updated_at".

    - `get_pending_segments(checkpoint: dict, all_segment_ids: list[int]) -> list[int]` —
      Return segment IDs not in completed and not exceeding max retry count in failed.
