  <action>
Create the src/matching/ package with Pydantic data models:

**SpeakerAnnotation** — represents a single LibriTTS-P speaker:
- `speaker_id: str` — numeric ID as string (e.g., "7335")
- `traits: list[str]` — merged perception/impression words from all annotators (e.g., ["feminine", "adult-like", "calm", "intellectual"])
- `trait_text: str` — comma-joined traits for display and embedding (computed property or set at load time)
- `gender: str` — inferred from traits: "male" if "masculine" in traits, "female" if "feminine" in traits, else "unknown"
- `annotator_agreement: dict[str, int]` — how many annotators (1-3) agree on each trait word

**VoiceAssignment** — a single character-to-speaker mapping:
- `character_name: str` — canonical name from CharacterProfile
- `speaker_id: str` — LibriTTS-P speaker ID
- `clip_path: str` — relative path to reference WAV within LibriTTS-R directory
- `reasoning: str` — brief explanation of why matched (per user decision: "casting director" style)
- `confidence: float` — 0.0-1.0 confidence score
- `is_major: bool` — whether this is a major character
- `method: str` — "llm" or "embedding" (which matching method was used)
- `warning: str | None` — warning flag for weak matches (per user decision)

**VoiceMap** — the complete voice map output:
- `book_slug: str` — identifies the book
- `narrator: VoiceAssignment` — narrator voice assignment
- `characters: list[VoiceAssignment]` — all character assignments
- `metadata: dict` with `created_at`, `libritts_subset`, `total_speakers_evaluated`

**CastClassification** — result of classifying characters:
- `major: list[str]` — character names classified as major
- `minor: list[str]` — character names classified as minor
- `threshold: int` — dialogue count threshold used
- `narrator_mode: str` — "first_person" or "third_person"

Use Pydantic BaseModel with ConfigDict(strict=True) on value objects, consistent with Phase 2 patterns. VoiceMap should NOT use strict mode (container model per Phase 2 convention).

Create src/matching/__init__.py exporting the public API: `load_speaker_index`, `filter_candidates`, `classify_cast` (will be implemented in speaker_index.py).

<task type="auto">
  <name>Task 2: Speaker index loader with filtering and cast classification</name>
  <files>src/matching/speaker_index.py, tests/test_matching_models.py</files>
  <action>
Create speaker_index.py with three functions:

**load_speaker_index(data_dir: Path) -> dict[str, SpeakerAnnotation]:**
- Load df1_en.csv, df2_en.csv, df3_en.csv from data_dir using csv.reader with delimiter="|"
- Each CSV has no header row — format is `speaker_id|comma,separated,traits`
- For each speaker_id, collect traits from all 3 annotators:
  - Union all trait words across annotators
  - Track annotator_agreement: count how many annotators list each trait
- Infer gender from traits: check for "masculine"/"very masculine" -> "male", "feminine"/"very feminine" -> "female", else "unknown". Use any modifier (e.g., "very masculine" still counts as masculine).
- Set trait_text as comma-joined sorted traits
- Return dict keyed by speaker_id string
- Log count: "Loaded {N} speakers from LibriTTS-P"

**filter_candidates(index: dict[str, SpeakerAnnotation], gender: str, age_range: str = "unknown") -> list[SpeakerAnnotation]:**
- Filter by gender match (mandatory unless character gender is "unknown", in which case return all)
- Soft filter by age: map character age_range to LibriTTS-P trait keywords:
  - "child" -> ["young", "childish"]
  - "young adult" -> ["young", "adult-like"]
  - "middle-aged" -> ["adult-like", "middle-aged"]
  - "elderly" -> ["old", "middle-aged"]
  - "unknown" -> no age filter
- Age filter is soft: include speakers who match ANY age keyword, but if no speakers match, fall back to all gender-matched speakers
- Return sorted by speaker_id for determinism

**classify_cast(characters: list[dict], segments: list[dict], default_threshold: int = 5) -> CastClassification:**
- Count dialogue lines per character from attributed segments (where type=="dialogue")
- Characters with >= threshold dialogue lines are "major", rest are "minor"
- Adjust threshold for large casts: if >20 characters, use max(5, total_dialogue_lines // 20) as threshold
- Determine narrator_mode: check if any character name matches the most common "narrator" speaker in segments, or check for first-person pronouns in narration segments. Default to "third_person" if unclear.
- Return CastClassification with major/minor lists and threshold used
