**Private helper — silence duration resolver:**
```python
def _get_silence_ms(prev_segment: dict, curr_segment: dict, config: AssemblyConfig) -> int:
```
Logic:
- If `curr_segment["type"] == "chapter_heading"`: return `config.chapter_silence_ms`
- If `prev_segment["type"] == "scene_break"` or `curr_segment["type"] == "scene_break"`: return `config.scene_break_silence_ms`
- Use segment IDs to detect paragraph boundaries: if IDs are non-consecutive (gap > 1) or this is a heuristic — for now, default to `config.paragraph_silence_ms` between segments (paragraph-level). The actual sentence-level silence applies when segments are split from the same source sentence, but since Phase 1 segmenter already produces paragraph-level segments, paragraph_silence_ms is the correct default.
- Return `config.paragraph_silence_ms` as default.

NOTE: The sentence_silence_ms value exists in config for future use if sub-paragraph segments are detected. For now, all segment boundaries are at least paragraph-level from the Phase 1 segmenter.

**Public function — chapter assembly:**
```python
def assemble_chapter(
    segment_wavs: list[tuple[dict, Path]],
    config: AssemblyConfig,
    announcement_wav: Path | None = None,
) -> AudioSegment:
```

Parameters:
- `segment_wavs`: list of (segment_metadata_dict, wav_file_path) tuples, in order
- `config`: AssemblyConfig with silence durations
- `announcement_wav`: optional path to chapter announcement WAV (TTS-generated "Chapter X: Title")

Implementation:
1. Start with `AudioSegment.empty()`.
2. If `announcement_wav` is provided and exists:
   - Load it: `AudioSegment.from_wav(str(announcement_wav))`
   - Append to chapter_audio
   - Append silence: `AudioSegment.silent(duration=config.post_announcement_silence_ms)`
3. Iterate through `segment_wavs`:
   - Load WAV: `AudioSegment.from_wav(str(wav_path))`
   - If not the first segment, insert silence using `_get_silence_ms(prev_meta, curr_meta, config)`
   - Append segment audio
   - Track prev_meta for next iteration
4. Append anti-truncation padding: `AudioSegment.silent(duration=config.anti_truncation_padding_ms)`
5. Return the assembled AudioSegment.
