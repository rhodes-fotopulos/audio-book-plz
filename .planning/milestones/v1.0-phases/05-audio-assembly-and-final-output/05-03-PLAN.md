  - `TIT2` (title): chapter_title (e.g., "Chapter 1: The Beginning")
  - `TPE1` (artist): author
  - `TALB` (album): title (book title)
  - `TCON` (genre): "Audiobook"
  - `TRCK` (track): f"{track_number}/{total_tracks}"
- If cover_data is not None:
  - Add `APIC` frame with encoding=Encoding.UTF8, mime=cover_mime, type=PictureType.COVER_FRONT (3), desc="Cover", data=cover_data
- Save tags.

**Tag combined audiobook MP3 with chapter markers:**
```python
def tag_audiobook(
    mp3_path: Path,
    title: str,
    author: str,
    chapters: list[ChapterInfo],
    cover_data: bytes | None = None,
    cover_mime: str | None = None,
) -> None:
```
- Load or create ID3 tags (same error handling as above).
- Set basic tags: TIT2 (title), TPE1 (author), TALB (title), TCON ("Audiobook").
- If cover_data, add APIC frame.
- Add CTOC (table of contents):
  - element_id="toc"
  - flags=CTOCFlags.TOP_LEVEL | CTOCFlags.ORDERED
  - child_element_ids: [f"chp{i:03d}" for i in range(len(chapters))]
  - sub_frames: [TIT2(encoding=Encoding.UTF8, text=["Table of Contents"])]
- Add CHAP frames for each chapter:
  - element_id=f"chp{i:03d}" (zero-padded to prevent ordering issues per research)
  - start_time=chapter.start_ms
  - end_time=chapter.end_ms
  - sub_frames: [TIT2(encoding=Encoding.UTF8, text=[chapter title])]
- Save tags.

Imports: mutagen.id3 (ID3, TIT2, TPE1, TALB, TCON, TRCK, APIC, CTOC, CHAP, CTOCFlags, Encoding), mutagen.mp3 (MP3), mutagen.id3 (ID3NoHeaderError). pathlib.Path. ChapterInfo from src/assembly/models.
Use `from __future__ import annotations`.

```python
def run_assembly(
    book_dir: Path,
    epub_path: Path | None = None,
    title_override: str | None = None,
    author_override: str | None = None,
    cover_override: Path | None = None,
    device: str = "auto",
) -> AssemblyStats:
```

**Full assembly pipeline (processed chapter by chapter to bound memory):**

1. **Validate inputs:**
   - Check `book_dir/wavs/` exists with WAV files.
   - Check `book_dir/voice_map.json` exists.
   - Check `book_dir/attributed.json` exists.
   - Fail early with clear error messages if any missing.

2. **Check FFmpeg:** Call `check_ffmpeg()` from encoder.

3. **Load data:**
   - Load attributed.json for segment metadata (chapter numbers, types, titles).
   - Load voice_map.json for narrator reference clip path.
   - Group segments by chapter_num. Extract unique chapters with titles.

4. **Extract EPUB metadata (if epub_path provided):**
   - Call `extract_epub_metadata(epub_path)`.
   - Apply overrides: title_override, author_override, cover_override (read cover file bytes if provided).
   - If no epub_path, use title_override or "Unknown Title", author_override or "Unknown Author".

5. **Generate chapter announcements:**
   - Determine narrator reference clip from voice_map.json (narrator.clip_path).
   - Call `generate_announcements(chapters_list, narrator_ref_path, book_dir / "announcements", device)`.
   - Print progress: "Generated {N} chapter announcements"

6. **Process each chapter (memory-bounded loop):**
   - Create `chapters/` directory inside book_dir.
   - For each chapter (ordered by chapter_num):
     a. Collect WAV paths: `book_dir/wavs/segment_{id:06d}.wav` for each segment in chapter.
     b. Build segment_wavs list: [(segment_meta, wav_path), ...]
     c. Get announcement WAV path for this chapter (if exists).
     d. Call `assemble_chapter(segment_wavs, config, announcement_wav)` → AudioSegment.
     e. Call `normalize_audio(chapter_audio, config.target_lufs)` → normalized AudioSegment.
     f. Export: `export_chapter_mp3(normalized, chapters_dir / f"chapter_{num:03d}.mp3", config.mp3_bitrate)`.
     g. Tag chapter: `tag_chapter(mp3_path, title, author, chapter_title, track_num, total_tracks, cover_data, cover_mime)`.
     h. Record ChapterInfo with duration_ms (from len(chapter_audio)).
     i. Print progress per chapter: "Chapter {N}/{total}: {title} ({duration})"

7. **Combine into audiobook.mp3:**
   - Calculate chapter start/end offsets (cumulative milliseconds) for CHAP frames.
   - Call `combine_chapter_mp3s(chapter_mp3_paths, book_dir / "audiobook.mp3", config.mp3_bitrate)`.
   - Tag combined: `tag_audiobook(audiobook_path, title, author, chapters_with_offsets, cover_data, cover_mime)`.

8. **Return AssemblyStats** with totals.
