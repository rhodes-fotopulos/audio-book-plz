Create `src/assembly/normalizer.py` with:

```python
def normalize_audio(audio_segment: AudioSegment, target_lufs: float = -19.0) -> AudioSegment:
```

Implementation:
1. Convert pydub AudioSegment to numpy float32 array:
   - `samples = np.array(audio_segment.get_array_of_samples(), dtype=np.float32)`
   - Normalize to [-1.0, 1.0]: `samples = samples / (2 ** (audio_segment.sample_width * 8 - 1))`
   - If stereo, reshape: `samples.reshape((-1, audio_segment.channels))` — but our audio is mono from Chatterbox so this is a safety check.

2. Create pyloudnorm meter: `meter = pyln.Meter(audio_segment.frame_rate)`

3. Measure current loudness: `current_lufs = meter.integrated_loudness(samples)`

4. Handle edge cases:
   - If `current_lufs == float('-inf')`: audio is silent, return unchanged.
   - If audio is shorter than 400ms (pyloudnorm needs at least one gating block): return unchanged with a warning logged.

5. Normalize: `normalized = pyln.normalize.loudness(samples, current_lufs, target_lufs)`

6. Convert back to int16:
   - `normalized = np.clip(normalized, -1.0, 1.0)`
   - `normalized_int = (normalized * (2**15 - 1)).astype(np.int16)`

7. Create new AudioSegment from normalized bytes:
   - `return audio_segment._spawn(normalized_int.tobytes())`

Imports: numpy, pyloudnorm as pyln, pydub.AudioSegment. Use `from __future__ import annotations`.

NOTE: Normalization is per-chapter (not per-segment) per research — this prevents short-segment measurement instability. The assembler orchestrator calls this once per chapter AudioSegment after concatenation.
