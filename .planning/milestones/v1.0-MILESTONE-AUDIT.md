## Integration Check Results

### BLOCKING: WAV Path Mismatch (Phase 4 → Phase 5)

Phase 4 synthesizer writes WAV files to: `wavs/ch{NN}/seg_{NNNN}.wav`
Phase 5 assembler expects: `wavs/segment_{NNNNNN}.wav`

The assembler will find zero WAV files, produce empty chapter audio, and output an audiobook containing only chapter announcements and silence. This breaks the core value proposition.

**Affects:** SYNTH-01, AUDIO-01, AUDIO-02, AUDIO-03, AUDIO-04

### BLOCKING: run_full_pipeline Only Runs Phases 1-2

`python main.py convert book.epub` only runs parse and attribute. Phases 3-5 print stub messages. The `run_match`, `run_synthesize`, and `run_assemble` functions exist but are not called.

**Affects:** CLI-01

### BREAKING (First Run): CharacterProfile Strict Mode Bug

`orchestrator.py:74` uses `CharacterProfile(**c)` which fails under Pydantic strict mode because nested dicts (VoiceQualities, Relationship) are not coerced. Should use `CharacterProfile.model_validate(c)`.

**Affects:** VOICE-01, VOICE-02, VOICE-03, VOICE-04, VOICE-05

### BREAKING: Announcer Placeholder Clip Path Crash

When Phase 3 runs without `--libritts-audio`, narrator clip_path is set to `AUDIO_DIR/{id}/longest.wav`. The announcer raises `FileNotFoundError` on this placeholder. Synthesizer handles this gracefully; assembler does not.

**Affects:** AUDIO-01, AUDIO-04
