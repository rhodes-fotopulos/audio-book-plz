<objective>
Remove the emotion annotation system and add speech-act feature flags.

Purpose: The emotion system (scene moods + line overrides) is being removed because Qwen3-TTS Base model cannot combine voice cloning with emotion instructions. Speech-act post-processing is made opt-in (default OFF) because LUFS normalization undoes volume deltas. Speech-act LLM refinement is made optional (default regex-only) to save LLM calls.

Output: Pipeline without emotion module, speech-act flags wired through CLI -> SynthesisConfig -> synthesizer, speech-act LLM pass optional.
</objective>
