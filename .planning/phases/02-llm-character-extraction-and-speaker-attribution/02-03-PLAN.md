    Create `src/attribution/attributor.py` that assigns a speaker to every segment.

    **Constants:**
    - `REGISTRY_BUDGET_TOKENS = 2000` — tokens reserved for character registry in prompt
    - `AVAILABLE_FOR_CONTENT = CONTEXT_WINDOW - 500 - 4096 - REGISTRY_BUDGET_TOKENS` — ~26,172 tokens for segment text
    - `MAX_CONTENT_CHARS = AVAILABLE_FOR_CONTENT * 4` — character limit for chapter segments
    - `CONFIDENCE_FLAG_THRESHOLD = 0.7` — attributions below this are flagged in stats

    **System prompt for attribution** (stored as module-level constant `ATTRIBUTION_SYSTEM_PROMPT`):
    ```
    You are a dialogue attribution specialist for audiobook production. For each segment, identify who is speaking.

    Character Registry (these are the characters in this book):
    {registry_json}

    Rules:
    - For dialogue segments: Identify the speaker from the character registry. Use the canonical name from the registry.
    - For narration, chapter headings, and scene breaks: Set speaker to "narrator".
    - Internal monologue and thoughts: Set speaker to "narrator" (narrator reads all non-spoken text).
    - Group dialogue ("they all shouted"): Set speaker to "narrator".
    - When a dialogue line has no explicit tag ("said X"), infer the speaker from:
      1. Turn-taking pattern (alternating speakers in conversation)
      2. Surrounding narration context ("she turned to him" before a dialogue line)
      3. Content/vocabulary matching known character speech patterns
    - Confidence scoring:
      - 1.0: Explicit attribution ("X said") or non-dialogue (always narrator)
      - 0.8-0.99: Strong contextual evidence (clear turn-taking, adjacent narration)
      - 0.5-0.79: Moderate inference (conversation flow, some ambiguity)
      - 0.1-0.49: Weak guess (multiple candidates, little context)
    - Always provide your best guess — never leave speaker empty or null
    - The reasoning field should briefly explain WHY you chose this speaker (1 sentence)
    ```

    **`_format_registry_for_prompt(characters: list[CharacterProfile]) -> str`:**
    - Formats the character registry as a compact JSON-like summary for the LLM prompt
    - Each character: `"Name (aliases: X, Y) - gender, age_range, traits: [a, b]"`
    - Keep it concise to stay within REGISTRY_BUDGET_TOKENS

    **`attribute_non_dialogue(segments: list[dict]) -> list[dict]`:**
    - For segments with type "narration", "chapter_heading", or "scene_break":
      - Set speaker = "narrator", confidence = 1.0
    - Returns the segments (modified in place)
    - These segments do NOT need LLM calls (ATTR-04)

    **`attribute_chapter(chapter_segments: list[dict], characters: list[CharacterProfile], chapter_num: int, cache_dir: Path) -> list[dict]`:**
    - First: Apply `attribute_non_dialogue` to handle non-dialogue segments
    - Separate dialogue segments that still need attribution
    - If no dialogue segments in this chapter: return early (all already attributed)
    - Compute cache key via `get_cache_key(chapter_text_for_dialogue, "attribution")`
    - Check cache — if hit, apply cached attributions to segments and return
    - Build prompt: system prompt with formatted registry + user content with numbered dialogue segments including 2 surrounding segments of context each:
      ```
      Segment {id} (type: {type}): {text}
      [Context before: "{prev_segment_text}"]
      [Context after: "{next_segment_text}"]
      ```
    - If dialogue segments exceed MAX_CONTENT_CHARS, split into batches and make multiple LLM calls
    - Call `call_llm_structured(system_prompt, user_content, ChapterAttributionResult)`
    - If LLM returns None: set speaker="unknown", confidence=0.0 for remaining dialogue segments
    - Match returned SegmentAttribution objects to segments by segment_id
    - Write successful results to cache
    - Return attributed segments

    **`attribute_all_segments(segments: list[dict], characters: list[CharacterProfile], cache_dir: Path, progress_callback: Callable | None = None) -> list[dict]`:**
    - Group segments by chapter
    - For each chapter: call `attribute_chapter`
    - If progress_callback: call it after each chapter with (chapter_num, total_chapters)
    - Return flat list of all segments (now with speaker and confidence fields)
  </action>
