  <name>Task 2: Create LLM client wrapper and cache module</name>
  <files>

  <action>
    1. Create `src/attribution/llm_client.py`:

    **Constants:**
    - `MODEL = "qwen3:8b"` — model name for Ollama
    - `CONTEXT_WINDOW = 32768` — explicit num_ctx
    - `MAX_RESPONSE_TOKENS = 4096` — num_predict limit
    - `MAX_RETRIES = 3` — retry count for failed calls
    - `NOTHINK_SUFFIX = " /no_think"` — appended to system prompts to disable Qwen3 thinking mode

    **`call_llm_structured(system_prompt: str, user_content: str, schema_class: type[BaseModel], num_ctx: int = CONTEXT_WINDOW) -> BaseModel | None`:**
    - Appends NOTHINK_SUFFIX to system_prompt
    - Calls `ollama.chat()` with:
      - `model=MODEL`
      - `messages=[{"role": "system", "content": system_prompt}, {"role": "user", "content": user_content}]`
      - `format=schema_class.model_json_schema()`
      - `options={"temperature": 0, "num_ctx": num_ctx, "num_predict": MAX_RESPONSE_TOKENS}`
    - Validates response with `schema_class.model_validate_json(response.message.content)`
    - On ValidationError or any Exception: log warning, retry up to MAX_RETRIES
    - After all retries exhausted: log error, return None
    - Uses Python `logging` module (logger = logging.getLogger(__name__))

    **`unload_model(model: str = MODEL) -> None`:**
    - Calls `ollama.chat(model=model, messages=[], keep_alive=0)` to free memory
    - Wraps in try/except to handle connection errors gracefully (Ollama might not be running)

    **`estimate_tokens(text: str) -> int`:**
    - Returns `len(text) // 4` — conservative 1:4 char-to-token ratio for English
    - Used by extractor/attributor to check if chapter fits in context window

    2. Create `src/attribution/cache.py`:

    **`get_cache_key(content: str, pass_name: str) -> str`:**
    - Computes `hashlib.sha256(f"{pass_name}:{content}".encode()).hexdigest()`
    - `pass_name` differentiates extraction vs attribution cache entries

    **`check_cache(cache_dir: Path, key: str) -> dict | None`:**
    - Looks for `cache_dir / f"{key}.json"`
    - If exists: returns parsed JSON (json.loads)
    - If not exists: returns None

    **`write_cache(cache_dir: Path, key: str, data: dict) -> None`:**
    - Creates cache_dir if needed (mkdir parents=True, exist_ok=True)
    - Writes data as JSON to `cache_dir / f"{key}.json"` with indent=2, ensure_ascii=False
    - Uses atomic write pattern: write to `.tmp` file first, then rename (prevents corruption on crash)

    **`clear_cache(cache_dir: Path) -> int`:**
    - Removes all `.json` files in cache_dir
    - Returns count of files removed
    - Used when user wants a fresh re-run
  </action>
