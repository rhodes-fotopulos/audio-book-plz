<task type="auto">
  <name>Task 2: Create hybrid speech-act classification module</name>
  <files>src/attribution/speech_acts.py</files>
  <action>
  Create `src/attribution/speech_acts.py` with:

  1. **Regex patterns for speech-act detection** (operate on dialogue segments + surrounding narration context):

     SHOUTED patterns (check narration context around dialogue):
     - re.compile(r'\b(shout|scream|yell|bellow|roar|exclaim|bark|thunder)(?:ed|ing|s)?\b', re.I) — explicit tags in narration
     - re.compile(r'!{2,}') — multiple exclamation marks in dialogue text
     - re.compile(r'\b[A-Z]{3,}\b') — ALL-CAPS words in dialogue (3+ chars, excluding "I")

     WHISPERED patterns (check narration context):
     - re.compile(r'\b(whisper|murmur|hiss|breathe|mutter|mumble)(?:ed|ing|s)?\b', re.I) — explicit tags

     THOUGHT patterns (check narration context + dialogue markers):
     - re.compile(r'\b(thought|wondered|mused|pondered|reflected|realized|considered)\b', re.I) — explicit thought verbs
     - re.compile(r'\bto\s+(?:her|him|them|it)self\b', re.I) — "to herself" pattern
     - Italicized content detection if segment text was originally italic (check for marker)

  2. **`classify_speech_act_regex(text: str, context_before: str, context_after: str) -> tuple[str, float]`**:
     - Check narration context (before and after) for speech-act tags first
     - Then check dialogue text itself for patterns
     - Return (speech_act, confidence) — "shouted" at 0.9 when narration says "he shouted", etc.
     - Default: ("spoken", 0.5) when no patterns match
     - Confidence: 0.9 for explicit narration tags ("she whispered"), 0.7 for text patterns (ALL-CAPS, !!)

  3. **`classify_speech_acts_llm(segments: list[dict], chapter_num: int) -> dict[int, tuple[str, float]]`**:
     - Takes dialogue segments with context (same batch as attribution)
     - Builds a prompt asking LLM to classify each segment's speech-act: spoken/thought/shouted/whispered
     - Uses `call_llm_structured()` with `SpeechActResult` schema
     - Returns dict mapping segment_id to (speech_act, confidence)
     - System prompt: "Classify each dialogue line's delivery style. Consider: surrounding narration (he whispered, she shouted), punctuation (!! for shouting), content (internal monologue vs spoken), and context (thought verbs like 'wondered')."

  4. **`classify_speech_acts(segments: list[dict], chapter_num: int) -> list[dict]`**:
     - Main entry point. Takes chapter segments (full list, including narration for context).
     - Pass 1: Run regex on all dialogue segments with surrounding context
     - Pass 2: For segments where regex confidence < 0.8, batch to LLM for refinement
     - Merge: LLM always wins when it returns a result (per user decision). If LLM returns None (failure), keep regex result.
     - Apply speech_act to each dialogue segment dict
     - Set non-dialogue segments to speech_act="spoken" (default/baseline)
     - Return modified segments
  </action>
  <verify>
  Run: `uv run python -c "from src.attribution.speech_acts import classify_speech_act_regex; tag, conf = classify_speech_act_regex('Hello world', 'she whispered,', ''); print(f'{tag}: {conf}')"`
  Should print: `whispered: 0.9`
  </verify>
  <done>
  speech_acts.py exports classify_speech_acts() for chapter-level classification, classify_speech_act_regex() for pattern-based detection, and classify_speech_acts_llm() for LLM refinement. Regex handles obvious cases (narration tags, ALL-CAPS, multiple exclamation marks), LLM handles ambiguous cases. LLM wins on conflict per user decision.
  </done>
