       - Check `book_dir / "voice_map.json"` exists. Error if not: "Run 'match' first."

       - Load attributed.json as list of dicts.

    3. **Dry run mode** (per user decision: `synthesize --dry-run` shows segment count, estimated time, disk space):
       - Count total segments (filter by chapter if --chapter).
       - Count chapters.
       - Estimate synthesis time: segments * 4.5 seconds (1.5x real-time factor * ~3s avg audio).
       - Estimate disk space: segments * 3.0 seconds * 48000 bytes/second (24kHz 16-bit mono WAV).
       - Print Rich table:
         ```
         ┌──────────────────────────────────┐
         │       Dry Run Estimate           │
         ├──────────────────┬───────────────┤
         │ Chapters         │ 24            │
         │ Segments         │ 2847          │
         │ Est. audio       │ ~8h 32m       │
         │ Est. wall time   │ ~12h 48m      │
         │ Est. disk space  │ ~1.4 GB       │
         │ WAV output       │ output/book/wavs/ │
         └──────────────────┴───────────────┘
         ```
       - Return early (no synthesis).

    4. **Create SynthesisConfig:**
       - If cpu=True: set device="cpu".
       - Otherwise: device="auto" (MPS detection).

    5. **Call run_synthesis():**
       - Pass book_dir, voice_map, attributed_segments, config, chapter, verbose.
       - Catch KeyboardInterrupt: print "Synthesis interrupted. Checkpoint saved — resume with same command."

    6. **Print completion summary:**
       - Use `rprint` consistent with other pipeline phases.
       - Show wavs directory path and total audio duration.

    7. **Return** wavs_dir path.

    **main.py** — Replace stub `synthesize` command:

    ```python
    @app.command()
    def synthesize(
        book_dir: Path = typer.Argument(
            ...,
            help="Output directory for a specific book (e.g. output/the-name-of-the-wind/)",
        ),
        chapter: int = typer.Option(
            None,
            help="Synthesize only this chapter number (useful for voice testing)",
        ),
        dry_run: bool = typer.Option(
            False,
            "--dry-run",
            help="Show estimated time and disk space without synthesizing",
        ),
        verbose: bool = typer.Option(
            False,
            "-v", "--verbose",
            help="Show per-segment detail during synthesis",
        ),
        cpu: bool = typer.Option(
            False,
            "--cpu",
            help="Force CPU mode (skip MPS acceleration)",
        ),
    ) -> None:
        """Synthesize audio segments with Chatterbox TTS."""
        # Validate prerequisites
        voice_map_file = book_dir / "voice_map.json"
        attributed_file = book_dir / "attributed.json"

        if not voice_map_file.exists():
            rprint(
                f"[red]Error:[/red] voice_map.json not found in [bold]{book_dir}[/bold]. "
                "Run 'match' first."
            )
            raise typer.Exit(code=1)

        if not attributed_file.exists():
            rprint(
                f"[red]Error:[/red] attributed.json not found in [bold]{book_dir}[/bold]. "
                "Run 'attribute' first."
            )
            raise typer.Exit(code=1)

        run_synthesize(book_dir, chapter=chapter, dry_run=dry_run, verbose=verbose, cpu=cpu)
    ```
