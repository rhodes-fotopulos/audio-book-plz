    **src/synthesis/progress.py** — SynthesisProgress class:

    Handles all user-facing output during synthesis. Two modes per user decision:
    - **Default:** Chapter-level progress bar ("Chapter 3/24 — segment 47/312")
    - **Verbose (-v):** Adds per-segment scrolling log (character name, duration, time taken)

    Class: `SynthesisProgress`

    - `__init__(self, total_chapters: int, total_segments: int, wavs_dir: Path, verbose: bool = False)`:
      - Store totals and mode.
      - Open `synthesis.log` file handle in `wavs_dir / "synthesis.log"` for append-mode writing.
      - Initialize `rich.progress.Progress` with:
        - A chapter-level task: `"[bold blue]Chapter {chapter}/{total_chapters}[/bold blue]"`
        - A segment-level task: `"Segment {segment}/{total_segments}"`
        - ETA column using `rich.progress.TimeRemainingColumn`
      - Initialize rolling average tracker: list of recent generation times (keep last 20).
      - Track completed count, failed count, total audio duration.

    - `start(self)` — Enter Rich progress context (call `progress.start()`).

    - `update_chapter(self, chapter_num: int, chapter_title: str)` — Update chapter-level progress description. Log to synthesis.log: `"=== Chapter {chapter_num}: {chapter_title} ==="`.

    - `update_segment(self, result: SegmentResult)` — Called after each segment:
      1. Advance segment-level progress by 1.
      2. Update rolling average with result.generation_time_s.
      3. Update ETA based on rolling average * remaining segments.
      4. If verbose: print segment detail line via `rich.print`: `"  {segment_id} | {character_name} | {duration_s:.1f}s audio | {generation_time_s:.1f}s gen"` (green if success, red if failed).
      5. Write to synthesis.log regardless of verbose mode: timestamp, segment_id, character, duration, generation_time, success/error.

    - `log_failure(self, segment_id: int, error: str, attempt: int, max_attempts: int)` — Write failure detail to synthesis.log and optionally print in verbose mode.

    - `log_message(self, message: str)` — Write timestamped message to synthesis.log and print to console.

    - `show_stats(self, stats: SynthesisStats)` — Called at end of run. Print Rich table:
      ```
      ┌──────────────────────────────────────┐
      │        Synthesis Complete             │
      ├────────────────────┬─────────────────┤
      │ Chapters           │ 24/24           │
      │ Segments completed │ 2835            │
      │ Segments failed    │ 12              │
      │ Segments cached    │ 0               │
      │ Total audio        │ 8h 23m          │
      │ Wall clock time    │ 12h 47m         │
      │ Avg time/segment   │ 4.2s            │
      └────────────────────┴─────────────────┘
      ```

    - `close(self)` — Stop Rich progress, close synthesis.log file handle.

    Use `rich.table.Table`, `rich.progress.Progress`, `rich.progress.BarColumn`, `rich.progress.TextColumn`, `rich.progress.TimeRemainingColumn`, `rich.progress.TimeElapsedColumn`.

    synthesis.log format (plain text, one line per event):
    ```
    2026-03-03T22:00:05Z | START | device=mps model=chatterbox-500m
    2026-03-03T22:00:05Z | CHAPTER | 1 | Chapter One
    2026-03-03T22:00:09Z | OK | seg_0000 | narrator | 3.2s audio | 4.1s gen
    2026-03-03T22:00:13Z | OK | seg_0001 | Elizabeth | 2.8s audio | 3.7s gen

    2026-03-03T23:45:00Z | DONE | 2835 ok | 12 failed | 8h23m audio | 12h47m wall
    ```

    **src/synthesis/synthesizer.py** — Main synthesis orchestration:

    `run_synthesis(book_dir: Path, voice_map: VoiceMap, attributed_segments: list[dict], config: SynthesisConfig, chapter: int | None = None, verbose: bool = False) -> SynthesisStats`:

    This is the core synthesis function. Steps:

    1. **Setup paths:**
       - `wavs_dir = book_dir / "wavs"` — Create if not exists.
       - WAV naming: `wavs/ch{chapter:02d}/seg_{segment_id:04d}.wav` (zero-padded chapter and global segment ID).

    2. **Load or create checkpoint:**
       - Call `load_checkpoint(book_dir)`. If exists, call `validate_checkpoint()` to detect missing WAVs and get re_queue list.
       - If no checkpoint: call `create_checkpoint()`.
       - Log how many segments are cached vs pending.

    3. **Filter segments:**
       - If `chapter` is not None: filter to only segments matching that chapter number (single-chapter mode per user decision).
       - Get pending segment IDs via `get_pending_segments()`.
       - If no pending segments: log "All segments already synthesized", return stats with skipped_cached count.

    4. **Build voice lookup:**
       - Create dict mapping character_name -> VoiceAssignment from voice_map.
       - Map "narrator" -> voice_map.narrator.
       - For segments with speaker "unknown" or not in voice_map: use narrator voice as fallback.

    5. **Group segments by chapter** for ordered processing.

    6. **Load TTS engine:**
       - Create TTSEngine, call `engine.load_model()`.
       - Log device and sample rate.

    7. **Initialize progress:**
       - Create SynthesisProgress with chapter/segment counts, verbose flag.

    8. **Main synthesis loop:**
       - For each chapter (ordered):
         - Update progress chapter display.
         - For each segment in chapter (ordered by segment_id):
           - Skip if already completed in checkpoint.
           - Look up voice assignment for segment's speaker.
           - Resolve ref_clip_path: use voice_assignment.clip_path. If clip_path starts with "AUDIO_DIR/", log warning (placeholder — no actual audio file).
           - Determine segment_type from segment["type"] (narration/dialogue).
           - Check for per-character exaggeration override in voice_map (if voice_map supports it in future, otherwise use config defaults).
           - **Retry loop (up to config.max_retries):**
             - Try: `wav = engine.generate(text, ref_clip_path, segment_type)`
             - Try: `success = engine.save_wav_atomic(wav, wav_path)`
             - On success: `mark_completed()`, update progress, break retry loop.
             - On failure: log error, increment attempt. If RuntimeError with "MPS" or OOM: call `engine.cleanup_memory()` before retry.
             - On final failure: `mark_failed()`, log to progress.
           - Save checkpoint after every segment (completed or failed).
           - Every `config.cleanup_interval` segments: call `engine.cleanup_memory()`.
           - **Check failure threshold:** If `failed / (completed + failed) > config.failure_threshold` AND `completed + failed >= 20` (minimum sample size): log error, stop run early, save checkpoint.

    9. **End-of-run retry pass** (per user decision: "Collect failures for a retry pass at end of run"):
       - Get all failed segments from checkpoint.
       - If any: log "Retrying {N} failed segments..."
       - For each failed segment: attempt one more generation.
       - On success: move from failed to completed in checkpoint.
       - Save checkpoint after retry pass.

    10. **Cleanup:**
        - Call `engine.unload()`.
        - Show stats via progress.show_stats().
        - Close progress.
        - Return SynthesisStats.

    **Handle Chatterbox crash recovery** (per user decision: "auto-restart Chatterbox once and resume from last checkpoint"):
    - If engine.generate() raises a fatal error (RuntimeError with "MPS" or similar GPU error) that persists after retries:
      - Log "Attempting Chatterbox restart..."
      - Call `engine.unload()` then `engine.load_model()`.
      - Set a flag `restarted_once = True`.
      - Continue from current segment.
      - If crash happens again after restart: save checkpoint, exit cleanly.

    **Segment text splitting safety net** (SYNTH-04):
    - Before generating: if `len(segment["text"]) > 280`, split at sentence boundaries using `nltk.tokenize.sent_tokenize()`.
    - Generate each sub-segment separately, concatenate WAV tensors with `torch.cat()`.
    - Save concatenated result as single WAV for the segment.

    3. `test_failure_threshold_stops_run` — Mock engine.generate to always fail, verify run stops after threshold exceeded.

    5. `test_end_of_run_retry_pass` — Mock failures that succeed on retry pass.
