**src/pipeline.py** — Create two public functions:

1. `run_parse(epub_path: Path, output_dir: Path) -> Path`: End-to-end parse phase.
   - Call `load_epub(str(epub_path))` to load the EPUB.
   - Call `get_story_chapters(book)` to get filtered chapter list.
   - Iterate chapters with `rich.progress.track()` for progress display (per user decision: "CLI shows progress during parsing" — use Rich's track, per research Pattern 8).
   - For each chapter:
     - Call `chapter_to_text_blocks(chapter)` to get text blocks.
     - Extract chapter title: look for the first `h1`/`h2`/`h3` block's text, or use empty string if no heading found.
     - Call `process_chapter_blocks(blocks, chapter_num, chapter_title, start_id)` to produce Segment objects.
     - Track `start_id` across chapters so segment IDs are globally sequential.
   - Generate book slug from EPUB filename: `epub_path.stem.lower().replace(' ', '-').replace('_', '-')` — strip special characters, keep it filesystem-safe (per research discretion recommendation).
   - Write `segments.json` to `output_dir / book_slug / segments.json` using `json.dump([dataclasses.asdict(s) for s in segments], f, ensure_ascii=False, indent=2)` (per research Pattern 6).
   - Print colored summary using `rich.print()` (per user decision: "CLI shows progress followed by a summary"):
     - Chapter count
     - Total segment count
     - Dialogue line count (segments with type == "dialogue")
     - Output file path
   - Return the path to `segments.json`.

2. `run_full_pipeline(epub_path: Path, output_dir: Path) -> None`: Orchestrates all 5 phases.
   - Call `run_parse()` first.
   - For Phases 2-5: print a message like `"[yellow]Phase 2 (attribute): not yet implemented[/yellow]"` and return.
   - No confirmation prompts — designed for unattended overnight runs (per user decision).
