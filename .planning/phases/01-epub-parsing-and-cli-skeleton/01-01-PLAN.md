**epub_reader.py** — Create two public functions:

1. `load_epub(path: str) -> epub.EpubBook`: Loads EPUB with ebooklib warning suppression. Use `warnings.filterwarnings("ignore", category=UserWarning, module="ebooklib")` in a context manager. Pass `options={'ignore_ncx': True}` to avoid NCX deprecation warning and force EPUB3 nav document usage (per research Pattern 7 and Pitfall 2/4).

2. `get_story_chapters(book: epub.EpubBook) -> list[epub.EpubHtml]`: Returns only story-relevant chapters in reading order, with front matter and back matter excluded.
   - Walk `book.spine` using `get_item_with_id()` — NEVER use `get_items_of_type(ITEM_DOCUMENT)` for ordering (per research Pitfall 1: manifest order != spine order).
   - Skip items where `linear == 'no'` (covers, footnotes, endnotes).
   - Implement hybrid front matter detection (per research Pattern 2, user decision on chapter detection):
     - **Tier 1:** Check `book.guide` for guide refs with `type` in `('text', 'bodymatter')`. If found, exclude all chapters before that index.
     - **Tier 2:** If no guide match, scan chapters for first `<h1>` or `<h2>` containing "chapter", "part", "prologue", or a standalone number/Roman numeral pattern. Use BeautifulSoup on `get_body_content()` for this scan.
     - **Tier 3:** If neither works, include everything (per user decision: "When the parser can't confidently identify where the story starts, include everything rather than risk missing story content").
   - Back matter detection: After finding the story start, also scan from the end backwards. Exclude chapters whose headings match "acknowledgment", "about the author", "author bio", "reading guide", "also by", "excerpt", "preview", "note from the author", "discussion questions". Include "epilogue", "afterword", "coda", "postscript" (per user decision: include story-related endings).

**html_cleaner.py** — Create one public function:

1. `chapter_to_text_blocks(item: epub.EpubHtml) -> list[tuple[str, str, dict]]`: Returns list of `(tag_name, text, attrs)` tuples for each block element in reading order.
   - Parse `item.get_body_content()` with `BeautifulSoup(content, 'lxml')` — use lxml backend (per research: faster, handles malformed XHTML).
   - Iterate block-level tags: `p`, `div`, `h1`, `h2`, `h3`, `h4`, `hr`, `blockquote`.
   - For `<hr>` tags: yield `('hr', '', {})` — these are scene breaks.
   - For other tags: extract text via `tag.get_text(separator=' ', strip=True)`. Skip empty text results.
   - Preserve the tag's CSS class names in `attrs` dict as `{'class': tag.get('class', [])}` — needed for scene break class detection (per research Pitfall 7: some publishers use CSS classes like "break", "separator", "divider" for scene breaks).
   - Do NOT use `soup.get_text()` on the whole document — only iterate specific block tags (per research Pitfall 5: avoids nav/head/script content).
  </action>
