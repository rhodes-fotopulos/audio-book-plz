<objective>
Build voice consistency verification that compares every synthesized segment's speaker embedding against its character's reference voice and regenerates outliers.

Purpose: Prevent voice drift within a character across thousands of segments. When TTS produces audio that sounds too different from the reference, regenerate it up to 3 times, keeping the best attempt. Produce a report file for optional manual review of flagged segments.

Output: Voice verifier module with embedding comparison, regeneration loop, and report generation. Tests for threshold logic and edge cases.
</objective>

  <name>Task 1: Create voice consistency verifier with Resemblyzer embeddings</name>
  <files>src/synthesis/voice_verifier.py, pyproject.toml</files>
  <action>
  **In pyproject.toml:**

  Add `"Resemblyzer>=0.1.3"` to the dependencies list.

  **Create src/synthesis/voice_verifier.py:**

  1. `class VoiceConsistencyVerifier`:
     - `__init__(self, threshold: float = 0.60, max_regen: int = 3, min_duration_s: float = 2.0)`: Store params, lazy-load VoiceEncoder on first use.
     - `_get_encoder(self) -> VoiceEncoder`: Lazy-load Resemblyzer's VoiceEncoder on CPU. Store as instance attribute.
     - `build_reference_embeddings(self, voice_map: VoiceMap) -> dict[str, np.ndarray]`: For each character + narrator in voice_map, load their reference clip via `preprocess_wav()` and compute embedding via `embed_utterance()`. Return dict mapping character name to 256-dim embedding. Skip characters with placeholder clip paths (AUDIO_DIR/ prefix).
     - `compute_segment_embedding(self, wav_path: Path) -> np.ndarray | None`: Load WAV, check duration (skip if < min_duration_s), `preprocess_wav()`, `embed_utterance()`. Return None for too-short segments.
     - `cosine_similarity(self, a: np.ndarray, b: np.ndarray) -> float`: Compute `np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))`.
     - `check_segment(self, wav_path: Path, ref_embedding: np.ndarray) -> tuple[float, bool]`: Compute segment embedding, return (similarity, passes_threshold). Returns (1.0, True) for too-short segments (skip check).
     - `unload(self)`: Delete the encoder to free memory.

  2. `class ConsistencyReport`:
     - Accumulates results: `segments_checked: int`, `segments_passed: int`, `segments_regenerated: int`, `segments_flagged: list[dict]` (failed all regen attempts), `segments_skipped: int` (too short).
     - `add_result(self, seg_id: int, speaker: str, similarity: float, passed: bool, regenerated: bool, attempt: int)`: Record a result.
     - `add_flagged(self, seg_id: int, speaker: str, best_similarity: float, wav_path: str)`: Record a segment that failed all regen attempts.
     - `write_report(self, output_path: Path)`: Write JSON report with summary stats and flagged segment details.

  3. `run_voice_consistency(book_dir: Path, voice_map: VoiceMap, attributed_segments: list[dict], threshold: float = 0.60, max_regen: int = 3, engine_config: SynthesisConfig | None = None) -> ConsistencyReport`:
     - Create VoiceConsistencyVerifier with threshold and max_regen
     - Build reference embeddings from voice_map
     - Iterate all segments, grouped by chapter:
       - For each segment, find its speaker's reference embedding
       - Check segment WAV against reference
       - If below threshold AND engine_config is provided:
         - Create TTS engine, regenerate segment up to max_regen times
         - After each regen, check new embedding
         - If any regen passes threshold, keep it, record in report
         - If all fail, keep the BEST scoring attempt (highest cosine), flag in report
       - If below threshold AND no engine_config (verification-only mode):
         - Just flag in report without regeneration
     - Write report to `book_dir / "voice_consistency_report.json"`
     - Unload encoder
     - Return report

  CRITICAL: Always call `preprocess_wav()` from Resemblyzer before `embed_utterance()` — it handles resampling to 16kHz and normalization. Raw 24kHz WAVs will produce incorrect embeddings.

  Use `from pathlib import Path` for all file operations. Check `wav_path.exists()` before processing. Skip missing WAVs with a warning log.
