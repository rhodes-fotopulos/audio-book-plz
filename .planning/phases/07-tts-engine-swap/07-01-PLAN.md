2. Create `src/synthesis/engine_base.py`:
   - Define `AudioResult` as a simple dataclass holding audio data (as bytes or numpy array), sample_rate (int), and duration_s (float). This is the uniform type returned by all engines — no torch or mx types leak out.
   - Define abstract base class `TTSEngineBase(ABC)` with methods:
     - `load_model(self) -> None` — load the TTS model into memory
     - `generate(self, text: str, ref_clip_path: str, ref_transcript: str | None = None, segment_type: str = "narration") -> AudioResult` — generate audio for text using reference voice. Note: `ref_transcript` is new for Qwen3-TTS but optional for Chatterbox (which ignores it).
     - `save_wav_atomic(self, audio: AudioResult, output_path: str) -> bool` — save audio atomically with duration validation
     - `cleanup_memory(self) -> None` — release caches/buffers
     - `unload(self) -> None` — fully release the model
     - `sample_rate` property -> int
     - `engine_name` property -> str — returns identifier like "qwen3-tts-1.7b" or "chatterbox-500m"
     - `engine_version` property -> str — returns version string for checkpoint tagging
     - `ensure_ollama_unloaded(self) -> None` — shared helper (NOT abstract, concrete on base class). Move the existing Ollama unload logic from current `TTSEngine` into the base class since both engines need it.
   - The `save_wav_atomic` method should be concrete on the base class (not abstract) using `soundfile.write()` with numpy arrays. Both engines return `AudioResult` with numpy audio data, so saving is uniform. Preserve the atomic tmp-file + rename pattern and min_wav_duration_s validation from the current implementation.

   - Adapt the `generate()` signature to match the base class (accept `ref_transcript` param but ignore it — Chatterbox doesn't use transcripts).
   - The `generate()` method returns `AudioResult` — convert the torch.Tensor wav to numpy before wrapping: `np.array(wav.cpu())` (single-channel float32).
   - `engine_name` returns `"chatterbox-500m"`.
   - `engine_version` returns the chatterbox-tts package version (importlib.metadata).
   - `cleanup_memory()` uses the existing `gc.collect()` + `torch.mps.empty_cache()` pattern.
   - `save_wav_atomic()` is inherited from base class (no override needed).
   - Keep the late-import pattern for torch/torchaudio/chatterbox (imported inside methods, not at module level).
   - Do NOT modify the original `src/synthesis/tts_engine.py` yet — the new file coexists until Plan 07-03 wires everything together.

1. Create `src/synthesis/qwen_engine.py` — `QwenTTSEngine(TTSEngineBase)`:
   - Late imports: `import mlx.core as mx`, `from mlx_audio.tts.utils import load_model`, `import numpy as np`, `import soundfile as sf` — all inside methods, not at module level. This follows the established codebase pattern from Phase 4 (torch imports are also late).
   - `__init__(self, config: SynthesisConfig)`: Store config. Set `self.model = None`, `self._sample_rate = None`.
   - `load_model(self)`:
     a. Call `self.ensure_ollama_unloaded()` (inherited from base).
     b. `import mlx.core as mx` then set Metal cache limit: `mx.metal.set_cache_limit(int(config.mlx_cache_limit_gb * 1024**3))`.
     c. `from mlx_audio.tts.utils import load_model` then load: `self.model = load_model("mlx-community/Qwen3-TTS-12Hz-1.7B-Base-bf16")`.
     d. Store `self._sample_rate = self.model.sample_rate` (validate it's > 0, log the actual value).
     e. Log: "Qwen3-TTS 1.7B loaded on MLX Metal" with sample rate.
   - `generate(self, text, ref_clip_path, ref_transcript=None, segment_type="narration") -> AudioResult`:
     a. Validate model is loaded.
     b. Call `results = list(self.model.generate(text=text, ref_audio=ref_clip_path, ref_text=ref_transcript))`.
     c. Extract audio: `audio_mx = results[0].audio` (this is an mx.array).
     d. Convert to numpy: `import numpy as np; audio_np = np.array(audio_mx)`.
     e. Compute duration: `duration = len(audio_np) / self._sample_rate` (handle 1D or 2D array shape).
     f. Return `AudioResult(audio=audio_np, sample_rate=self._sample_rate, duration_s=duration)`.
     g. If ref_transcript is None, log a warning: "No transcript provided for voice cloning — quality may be reduced".
   - `cleanup_memory(self)`:
     a. `import mlx.core as mx`
     b. `mx.metal.clear_cache()`
     c. Log active and peak memory: `mx.metal.get_active_memory()`, `mx.metal.get_peak_memory()` in MB.
   - `unload(self)`:
     a. `self.model = None`
     b. `self.cleanup_memory()`
     c. Log "Qwen3-TTS model unloaded".
   - `sample_rate` property: return `self._sample_rate` (raise RuntimeError if model not loaded).
   - `engine_name` returns `"qwen3-tts-1.7b"`.
   - `engine_version`: try `importlib.metadata.version("mlx-audio")`, fallback to `"unknown"`.

2. Create `src/synthesis/engine_factory.py`:
   - `create_engine(config: SynthesisConfig) -> TTSEngineBase`:
     a. If `config.engine_type == "qwen3"`: lazy import `from src.synthesis.qwen_engine import QwenTTSEngine`, return `QwenTTSEngine(config)`.
     b. If `config.engine_type == "chatterbox"`: lazy import `from src.synthesis.chatterbox_engine import ChatterboxEngine`, return `ChatterboxEngine(config)`.
     c. Else: raise ValueError with supported engine types.
   - This factory pattern keeps heavy imports (torch OR mlx) lazy — only the selected engine's dependencies load.
