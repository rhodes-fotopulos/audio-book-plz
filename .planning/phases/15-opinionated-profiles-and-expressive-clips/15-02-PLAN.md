  <action>
  **In src/matching/audio_analyzer.py (NEW):**
  Create the full audio analysis module using numpy + soundfile (no librosa). Follow RESEARCH.md Pattern 4 closely for implementation.

  1. `analyze_clip(wav_path: Path) -> dict`: Read WAV with soundfile, convert stereo to mono. Return dict with snr_db, pitch_variance, energy_variance, syllable_rate, duration_s. For clips under 2 seconds, set snr_db=0 (per RESEARCH.md Pitfall 3).

  2. `_compute_snr(data: np.ndarray) -> float`: Sort amplitudes, bottom 10% is noise estimate. Return 20*log10(signal_rms/noise_rms). Clamp noise_rms to 1e-10 minimum.

  3. `_compute_pitch_variance(data: np.ndarray, sr: int) -> float`: Frame-based autocorrelation (30ms frames, 10ms hop). Skip silent frames (max abs < 0.01). Find first peak after initial decline in autocorrelation. Confidence threshold 0.3. Return variance of detected F0 values. Return 0.0 if fewer than 3 voiced frames.

  4. `_compute_energy_variance(data: np.ndarray, sr: int) -> float`: Frame-level RMS (30ms frames, 10ms hop). Return variance of frame energies.

  5. `_estimate_syllable_rate(data: np.ndarray, sr: int) -> float`: Compute RMS envelope (20ms frames, 10ms hop), smooth with 5-sample moving average, count peaks above 0.5*mean threshold. Return peaks/duration.

  6. `score_clip(metrics: dict, target_rate: float | None = None) -> float`: Normalize each component to 0-1 range:
     - SNR: clamp 0-40 dB, divide by 40
     - Pitch variance: clamp 0-5000 Hz^2, divide by 5000
     - Energy variance: clamp 0-0.01, divide by 0.01
     - Rate match: if target_rate and syllable_rate > 0, `max(0, 1.0 - abs(syllable_rate - target_rate) / 5.0)`, else 0.5
     - Return weighted sum: 0.4*snr + 0.3*pitch + 0.2*energy + 0.1*rate

  7. `PACE_TO_RATE` dict and `get_target_rate(voice_profile: VoiceProfile) -> float | None`: Map pace descriptors to target syllable rates. Try pace_style first (more specific), fall back to pace. "unknown" maps to None. See RESEARCH.md for full mapping.
