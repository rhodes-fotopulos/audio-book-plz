  6. Add `DistinctivenessResult(BaseModel)` with fields: `characters: list[CharacterProfile]` and `modifications: list[str]` (human-readable list of what changed).

  **In src/attribution/distinctiveness.py (NEW):**
  7. Create DISTINCTIVENESS_PROMPT constant (see RESEARCH.md Pattern 2). System prompt instructs LLM as voice casting director. Rules: every character distinguishable by 2+ traits, push apart the one with less textual evidence, return ALL profiles.
  8. Create `run_distinctiveness_pass(characters: list[CharacterProfile], cache_dir: Path) -> list[CharacterProfile]`:
     - Build user content: serialize all profiles as name + voice_profile fields only (not full CharacterProfile -- keep context small for Qwen 3.5 9B).
     - If >15 characters, batch into groups of 10-12, run multiple passes (each pass reviews a subset).
     - Use `call_llm_structured(DISTINCTIVENESS_PROMPT, user_content, DistinctivenessResult)`.
     - Cache with key `get_cache_key(user_content, "distinctiveness_v1")`.
     - Validate: returned character count must match input. If mismatch, log warning and return original profiles.
     - Match returned characters by name (case-insensitive). For matched characters, update their voice_profile from the LLM result. For unmatched, keep original.
     - Log all modifications from result.modifications.
     - Return updated list.
