<objective>
Implement per-character voice reference caching in the Qwen3-TTS engine so each character's reference audio is loaded and encoded once per synthesis run instead of once per segment.

Purpose: Eliminates redundant file I/O and neural codec encoding, which is the primary per-segment overhead (~100-500ms per call on M4).
Output: Modified qwen_engine.py with two-layer cache, updated synthesizer.py to pass character names, tests proving cache reuse.
</objective>

**QwenTTSEngine changes (src/synthesis/qwen_engine.py):**

1. Add `self._ref_cache: dict[str, Any] = {}` in `__init__` (stores character_name -> loaded mx.array audio).

2. Add `character_name: str | None = None` as an optional keyword argument to `generate()` (do NOT change the TTSEngineBase abstract signature -- add it only on QwenTTSEngine as a non-abstract override with the extra kwarg).

3. In `generate()`, implement two-layer cache:
   - Layer 1 (load_audio cache): Use `cache_key = character_name or ref_clip_path`. If `cache_key` in `self._ref_cache`, use the cached `mx.array`. Otherwise, call `from mlx_audio.utils import load_audio; ref_audio_array = load_audio(ref_clip_path, sample_rate=self._sample_rate)`, store in `self._ref_cache[cache_key]`, and log `logger.info("Cached reference encoding for %s", cache_key)`.
   - On cache hit, log `logger.debug("Using cached reference for %s", cache_key)`.
   - Pass `ref_audio=ref_audio_array` (the mx.array) to `self.model.generate()` instead of the string path. This skips mlx-audio's internal `load_audio()` call.

4. Layer 2 (encode wrapper): After `load_model()` loads the model, wrap `self.model.speech_tokenizer.encode` with a cache. Use Python `id()` of the mx.array as cache key (since we control the cache and pass the same object for the same character):
   ```python
   original_encode = self.model.speech_tokenizer.encode
   encode_cache: dict[int, Any] = {}
   def cached_encode(audio):
       key = id(audio)
       if key not in encode_cache:
           encode_cache[key] = original_encode(audio)
       return encode_cache[key]
   self.model.speech_tokenizer.encode = cached_encode
   self._encode_cache = encode_cache  # keep reference for cleanup
   ```

5. In `unload()`, clear `self._ref_cache` and `self._encode_cache` (if it exists) before calling `cleanup_memory()`.

6. In `cleanup_memory()`, do NOT clear the ref cache -- the research notes that reference audio arrays are small (~100KB each) and survive Metal cache clears since `mx.metal.clear_cache()` clears compute cache, not tensor storage.
