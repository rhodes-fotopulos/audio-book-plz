Add --batch-by-character CLI flag that reorders synthesis to process all segments per character consecutively, then writes WAVs to the same chapter-ordered paths for unchanged assembly.

Purpose: Keeps MLX model "warmed" for each voice's reference encoding, reducing memory thrashing between different voice profiles. Compounds the reference caching benefit from Plan 01.
Output: CLI flag, config field, batch iteration path in synthesizer, character progress display, tests.
