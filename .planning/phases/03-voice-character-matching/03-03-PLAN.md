**clip_selector.py — select_reference_clip(speaker_id: str, libritts_root: Path) -> str | None:**
- Search for speaker directories: glob `{libritts_root}/*/{speaker_id}` (covers any split like train-clean-360)
- Within speaker directory, find all .wav files recursively
- Select the largest WAV file (proxy for longest duration — WAV at 24kHz is proportional to size)
- If the largest WAV is under ~120KB (roughly 5 seconds at 24kHz mono 16-bit), log a warning
- Return the relative path from libritts_root (e.g., "train-clean-360/7335/166546/7335_166546_000028_000002.wav")
- Return None if speaker not found in audio files — set warning on VoiceAssignment

**orchestrator.py — run_matching(book_dir: Path, libritts_data_dir: Path, libritts_audio_dir: Path | None = None) -> VoiceMap:**

Full matching pipeline:

1. **Check for existing voice_map.json:**
   - If book_dir / "voice_map.json" exists, load and return it (per VOICE-05: re-runs read existing)
   - Print: "Using existing voice_map.json (delete to re-match)"
   - Return early

2. **Load inputs:**
   - Load characters.json from book_dir -> list[CharacterProfile]
   - Load attributed.json from book_dir -> list[dict] (segments)
   - Load speaker index from libritts_data_dir (the LibriTTS-P CSV directory)

3. **Classify cast:**
   - Call classify_cast(characters, segments)
   - Print summary: "Cast: {N} major, {M} minor characters (threshold: {T} dialogue lines)"

4. **Build embedding index (for fallback):**
   - Call build_speaker_embeddings(list(speaker_index.values()))
   - This runs on CPU, should take <10 seconds for 2,443 speakers

5. **Match narrator first:**
   - Filter candidates by narrator requirements
   - Call match_narrator_llm(characters, segments, narrator_candidates, narrator_mode, assigned_ids=set())
   - If LLM fails, use match_character_embedding as fallback
   - Track assigned speaker_id

6. **Match major characters (LLM primary):**
   - For each major character in order of dialogue count (most to least):
     - Filter candidates: filter_candidates(index, character.gender, character.age_range)
     - If >50 candidates after gender/age filter, use embedding pre-ranking to select top 30
     - Call match_character_llm(character, filtered_candidates, assigned_ids)
     - If LLM returns None, fall back to match_character_embedding
     - Add speaker_id to assigned_ids set
   - Print progress: "Matched {name} -> speaker {id} ({method})"

7. **Match minor characters (embedding preferred):**
   - For each minor character:
     - Use match_character_embedding (skip LLM for efficiency)
     - assigned_ids only excludes major character speakers (minors CAN share with other minors)
   - Print progress for minor characters too

8. **Enforce uniqueness:**
   - Call enforce_uniqueness(all_assignments, classification, segments, ...)

9. **Select reference clips (if audio dir provided):**
   - For each assignment, call select_reference_clip(speaker_id, libritts_audio_dir)
   - If audio dir not provided, set clip_path to placeholder: "AUDIO_DIR/{speaker_id}/longest.wav"

10. **Build VoiceMap object** with all assignments and metadata

11. **Return VoiceMap** (the caller — pipeline.py — handles display and confirmation)

Update src/matching/__init__.py to export run_matching and select_reference_clip.
